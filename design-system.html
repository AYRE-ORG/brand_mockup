Rule

Never use raw gold (#C19A3E) as a flat background on buttons. Always use the gradient. Flat gold looks cheap. Gradient gold looks premium. The gradient catches light and adds dimension.

05 — Loading States
Skeleton Loaders
Every data-dependent screen shows a branded skeleton while loading. No spinners. No blank screens.
Property Card Skeleton
/* Skeleton shimmer animation */ @keyframes shimmer { 0% { background-position: 200% 0; } 100% { background-position: -200% 0; } } .skeleton { background: linear-gradient(90deg, #F0F0F0 25%, #E8E8E8 50%, #F0F0F0 75%); background-size: 200% 100%; animation: shimmer 1.5s infinite; border-radius: 8px; }
Rule

The skeleton must match the layout of the content it replaces. Property card skeleton = image block + price line + address line + specs line. Dashboard stat skeleton = number block + label block. Zero layout shift when data loads.

Zero Dead Space Rule

If a section has no data, hide it entirely. Do not render an empty container. The footer must always sit directly below the last visible content section. Test every page by scrolling to the bottom — if there is more than 40px of empty space between the last content and the footer, it is a bug.
